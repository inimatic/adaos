# Privacy And Security

Status: public conceptual security page.

AdaOS should keep authority, data location, and runtime access explicit.

## Public Principles

- Local-first operation is preferred where it fits the product experience.
- Joining a node is an admission event, not an implicit trust grant for every
  capability.
- Applications should disclose user-visible access to files, devices,
  credentials, network services, and background work.
- Media Center should reference external libraries without copying media bytes
  unless the user chooses a managed import path.
- Public documentation should not expose internal operational topology,
  credentials, raw evidence, or private roadmaps.

## Current User Responsibility

Protect join codes, local tokens, configuration files, and any machine that can
act as a hub or member node.
