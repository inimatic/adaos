# AdaOS 2027 Documentation

Status: public scaffold for the 2027 documentation track.

AdaOS is a local-first platform for building and operating distributed
assistant environments that connect people, AI agents, applications, browsers,
and devices.

This documentation track describes implemented, supported, or explicitly beta
behavior. Internal target architecture, engineering roadmaps, raw evidence,
and product-management planning live outside the public repository.

## Public Product Focus

The first public track is intentionally narrow:

- **AdaOS Runtime Foundation**: local CLI, node runtime, hub/member topology,
  skills, scenarios, browser access, and runtime operations.
- **Media Center**: a beta-oriented applied solution for private media
  libraries and local browser playback.
- **Builder**: an experimental governed development workflow for turning an
  idea into an AdaOS application candidate.

aResearcher and reDevice remain important product directions, but they are not
documented as public stable 2027 offers until their evidence and packaging are
ready.

## Documentation Rules

- Public pages describe what a user can install, run, inspect, or try now.
- Beta pages must say what is ready, what is limited, and what evidence is
  still required.
- Roadmaps, target architecture, implementation references, and internal
  contracts are not published here.
- English is authoritative for this public track. Translations can follow after
  the English meaning stabilizes.
