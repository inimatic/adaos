# Solution Directions

Status: public product-direction summary.

AdaOS product language should separate deployment profiles, applied solutions,
and endpoint families.

## Publicly Documented Now

- **AdaOS Runtime Foundation**: the shared local-first runtime.
- **Media Center**: the first applied beta candidate.
- **Builder**: an experimental governed development workflow.

## Held For Later Public Tracks

- **aResearcher** needs effectiveness evidence and a publishable method before
  it becomes a public stable track.
- **reDevice** needs a device-owner journey, setup flow, and acceptance evidence
  before it becomes a public stable track.
- **Home, Campus, and Enterprise** remain useful deployment-profile language,
  but they should not imply packaged product availability until support and
  rollout boundaries are ready.
