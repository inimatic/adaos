Создай исполняемый локальный Prototype панели инфраструктуры на русском языке.
Нужны три раздела: «Обзор», «Инциденты», «Копии». Покажи заметное пояснение «Демонстрационные данные».
Сервер EU: name EU, CPU 32, disk 41, health healthy. Сервер RU: name RU, CPU 92, disk 78, health unhealthy. Сервер infra-01: name infra-01, CPU 21, disk 36, health healthy.
В разделе «Обзор» нужен поиск только по полю name серверов. Поиск RU оставляет только сервер RU; сброс поиска возвращает все три сервера.
Инцидент RU-I1 относится к серверу RU; status open, текст «Высокая загрузка CPU».
Для инцидента нужна локальная команда «Принять», меняющая status open на accepted. Команда меняет только status этого инцидента; CPU 92, disk 78 и health unhealthy сервера RU остаются прежними. Повтор не создаёт новый инцидент.
В разделе «Копии» покажи копию RU-backup для сервера RU: created_at 2026-10-29, root_version v0.1.0. Это дата создания, а не дата проверки.
На ширине 390 px все разделы, поиск и команда должны оставаться доступными без горизонтального переполнения.
Не добавляй реальные SSH, Root/API, device_control, внешние capabilities, живые dataSource, автообновление или уведомления. Только изолированные локальные данные Prototype.
Проверь исходные числовые значения, поиск и сброс, изменение status и сохранение остальных данных. Приёмка должна опираться на исполняемые связи и результат действий.
