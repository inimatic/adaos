# Автоматизация списка чтения

Реализуй постоянное хранение данных для согласованного прототипа списка чтения,
редакция 002. Это автоматизация существующего приложения, а не новый дизайн.
Сохрани расположение списка и подробностей, поиск и фильтр, русские подписи,
существующие формы создания, редактирования и удаления, их поля и переходы.
Вместо временных ресурсов прототипа используй принадлежащие приложению ресурсы
и поддерживаемые SDK операции. Не обращайся к данным других приложений.

Пользователь добавляет книгу с непустым названием. Автор, статус и заметка
необязательны. Для статуса допустимы имеющиеся три варианта или отсутствие
выбора. Название из одних пробелов недопустимо; проверка должна действовать
на сервере, а не только в браузере. После сохранения новая книга видна в
списке и доступна для выбора. Клик по записи показывает ее подробности;
редактирование меняет выбранную книгу и сохраняет многострочную заметку.
Отмена создания, редактирования или подтверждения удаления ничего не меняет.
Подтвержденное удаление удаляет только выбранную книгу и обновляет список.
Поиск работает по названию и автору совместно с фильтром статуса. Пустой
список и отсутствие результатов поиска остаются работоспособными состояниями.

Данные должны сохраняться после перезагрузки страницы и перезапуска приложения.
Первый запуск использует пустое постоянное хранилище; демонстрационные книги
прототипа не являются пользовательскими данными и не переносятся в него.
Не требуются учетные записи, внешние сервисы, синхронизация между подсетями,
новые разделы или перепроектирование интерфейса. Исправь оставшееся название
сценария из шаблона на название приложения и локализуй пустую детализацию.

Добавь исполняемые проверки CRUD, обязательного названия, необязательных полей,
поиска и фильтрации, отсутствующей записи и сохранности данных между запусками.
Укажи реально запущенные проверки и отдельно те, которые не выполнялись.
Не объявляй браузерную приемку пройденной: она проводится независимо после
получения реализации. Не готовь Trial и не публикуй приложение автоматически.
