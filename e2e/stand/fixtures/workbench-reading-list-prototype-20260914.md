Сделай прототип текущего приложения для моего списка чтения. Интерфейс на русском.
В списке у книги нужны название, автор и статус: хочу прочитать, читаю, прочитано.
Нужны поиск по названию или автору и фильтр по статусу. По клику на строке покажи
подробности выбранной книги, включая мою заметку. Из подробностей можно открыть
редактирование в отдельном окне. Создание книги тоже через отдельное окно.
Кнопка удаления доступна в подробностях. При отмене редактирования список не
меняется. Без названия сохранить книгу нельзя. Добавь несколько разнообразных
примеров, чтобы проверить поиск, фильтрацию и изменение статуса. Покажи понятное
пустое состояние, если список пуст или по поиску ничего не найдено.
Это этап прототипа: сейчас проверяем работающий интерфейс и локальные операции
на примерах; надёжное серверное хранение будет следующим заданием автоматизации.
